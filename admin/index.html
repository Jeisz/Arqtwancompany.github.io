Publicar

El editor nunca publica solo. Prepara una carpeta con los archivos exactos que debes subir a GitHub; la Action reconstruye y publica el sitio.

Repositorio de GitHub

Solo se usa para mostrarte el enlace de carga. No se envía nada a GitHub desde aquí.

Archivos que debes subir

    Si la lista está vacía, se subirá solo data/content.js. Las fotos que hayas cambiado se añaden solas.

    Pasos para publicar

    1. Pulsa Guardar y regenerar y revisa la Vista previa.
    2. Pulsa Preparar carpeta _publicar.
    3. Abre en el explorador de Windows la carpeta del proyecto y entra en _publicar.
    4. En GitHub, abre la página de carga del repositorio y arrastra la carpeta _publicar completa (no su contenido suelto).
    5. Escribe un mensaje de commit claro y pulsa Commit changes.
    6. Espera 1–2 minutos: la Action reconstruye el sitio y lo publica. Si falla, el sitio anterior sigue en línea.
